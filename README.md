# Personal Website

This project is a simple personal website built with plain HTML and CSS.

## Structure
- `index.html` — home page with a short bio, profile image placeholder, and resume link
- `portfolio.html` — portfolio page for class assignments and future project links
- `style.css` — shared styling for the site
- `assets/images/profile.jpg` — placeholder profile image
- `assets/resume.pdf` — placeholder resume link


## How to view it
Open `index.html` in a browser to view the site locally.
